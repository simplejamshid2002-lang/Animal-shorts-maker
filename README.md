Animal Shorts Maker


A free-start project for creating English YouTube Shorts about amazing animal facts.


Planned features




Generate short English animal-fact scripts


Prepare scene-by-scene video plans


Find suitable footage from Pexels


Add voiceover and subtitles


Render a vertical MP4 video


Review the video before uploading to YouTube




Important


Videos must be fact-checked, and footage must be used according to its license. Uploading will require human approval.
